# Chords contract and representational loss

LocalStore implements `ObjectStore.put(bytes) -> SHA256` and `get(SHA256) -> verified bytes`. All source bytes are retained, including replay/controller metadata. Object keys reject paths; existing content is checked. Application writes never overwrite objects. This is application-level immutability, not a cloud retention policy or multiwriter transactional service. Interrupted writes fail checksum validation visibly.

Each episode record references a Parquet signal/index object, per-camera video objects and raw-source manifest. Frame identities hash stable episode identity plus frame index. Episode identity includes the pinned revision; initialization-group identity excludes revision/windows/prefixes to prevent resplitting copies. The current episode is development-only; episode index is not simulator seed.

State16 is base position3, base quaternion xyzw4, relative EE position3, relative EE quaternion xyzw4, gripper qpos2. Canonical action12 is EE translation3, EE rotation3, gripper command1, base motion4, control mode1. This is a reversible reorder of measured source controller commands, not absolute pose targets or normalized actor predictions. The original action vector, modality, embodiment and detailed controller configuration remain raw objects. Source units/frame conventions are retained; unknown calibrations and command scaling are not invented. Clock is episode-relative seconds at 20 Hz; streams are aligned by index and presentation timestamp.

Annotations are separate versioned objects, referenced by immutable release manifests. Fork manifests retain parent identity and reuse base episode/video/signal objects plus selected annotation overlays. This minimal implementation exports one episode and one compatible schema; future physical shards group schemas/encodings rather than task × split × quality. There is no service, scheduler, cloud adapter, compaction or garbage collector yet. R2 is the intended portable object-storage foundation; CUDA workers can be replaced without owning dataset truth.

Xiaomi state14 conversion/padding, image history/crop, reorder, normalization and actor target masks belong in views. `window_indices` reports valid positions separately from clamped startup/tail indices. Done records episode termination, not success. Success and recovery remain unknown. Future selected-versus-random utility experiments must match unique eligible transition coverage and compute budgets; explored simulator seeds remain DEV. No runtime-intervention benefit is claimed.

## LeRobot v2.1 export

Pinned loader: [official Hugging Face LeRobot v0.3.3](https://github.com/huggingface/lerobot/tree/v0.3.3). The exporter preserves every original signal column and float64 state/action value, emits a one-episode collection, computes actual signal/video statistics and copies compatible H.264 MP4 bytes without transcoding. Export tests compare independent output trees byte-for-byte.

The official loader converts Python floating lists to default float32 tensors. Float64 values are preserved in Parquet/core but lose precision in loader tensors; verification reports maximum conversion errors and requires exact agreement with the official float32 conversion. Camera tensors are RGB float32 [0,1] decoded from compressed video; no original simulator RGB claim. All camera pixels and presentation timestamps are checked.

LeRobot's `train: 0:1` range describes the file collection; the source remains development-only via sidecar annotation. Do not treat the structural range as training eligibility. Stable frame/episode IDs, richer controller metadata, quality/split annotations, license/provenance and release/fork lineage are retained in `sidecars/`, outside the loader's standard schema. Raw-object references in sidecars require the originating Chords store; the exported directory alone does not contain raw replay XML/NPZ or a complete base store. Standard loader consumers ignore those sidecars. No labels are synthesized.
